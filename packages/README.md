# Packages Directory

This directory tracks all installed packages and dependencies for both the **Frontend** and **Backend** separately.

## Directory Structure

```
packages/
├── frontend/
│   ├── installed_packages.md    # Detailed overview and purpose of frontend packages
│   └── packages.txt             # Quick list of installed frontend packages
└── backend/
    ├── installed_packages.md    # Detailed overview and purpose of backend packages
    └── packages.txt             # Quick list of installed backend packages
```
